高中物理交变电源和法拉第电磁感应

一、法拉第电磁感应定律

这是电磁感应的核心，主要解决感应电动势大小的计算问题。

1. 核心公式：法拉第电磁感应定律

  • 公式： $$E = n\frac{\Delta \Phi}{\Delta t}$$ （普适公式）
  • 理解：
    • $n$：线圈的匝数。
    • $\frac{\Delta \Phi}{\Delta t}$：磁通量的变化率，它决定了感应电动势的大小，而不是磁通量 $\Phi$ 本身，也不是磁通量的变化量 $\Delta \Phi$ 。
    • $E$：在 $\Delta t$ 时间内的平均电动势。

2. 特例：导体切割磁感线

  • 公式：$$E = BLv \sin \theta$$
  • 理解：
    • $B$：匀强磁场的磁感应强度。
    • $L$：导体的有效长度（即导体在垂直于速度方向上的投影长度）。
    • $v$：导体的运动速度。
    • $\theta$：$B$ 与 $v$ 的夹角。当 $B、L、v$ 三者互相垂直时，公式简化为 $E = BLv$。
    • 如果 $v$ 是瞬时速度，则 $E$ 为瞬时电动势；如果 $v$ 是平均速度，则 $E$ 为平均电动势 。

3. 两个易混淆的物理量

做题时，一定要分清下面三个“磁”量：

  • 磁通量 $\Phi = BS$：指穿过回路磁感线的“条数”多少。
  • 磁通量变化量 $\Delta \Phi = \Phi_2 - \Phi_1$：指磁通量变化了的“数量”多少。
  • 磁通量变化率 $\frac{\Delta \Phi}{\Delta t}$：指磁通量变化的“快慢”程度。它与电动势大小直接相关 。

二、交变电流

这一章主要研究正弦式交变电流的产生和描述，解题的关键是熟练掌握“四值” 。

物理量 物理含义 重要公式 适用情况及说明
瞬时值 某一时刻的值 $e = E_m \sin \omega t$
$i = I_m \sin \omega t$		 计算线圈某一时刻的受力或电压、电流情况 。
最大值 (峰值) 电压或电流的最大数值 $E_m = nBS\omega$
$I_m = E_m / (R+r)$		 讨论电容器等元件的击穿电压（耐压值）时使用 。
有效值 根据电流的热效应定义 $E = \frac{E_m}{\sqrt{2}}$
$U = \frac{U_m}{\sqrt{2}}$
$I = \frac{I_m}{\sqrt{2}}$
（仅适用于正弦交流电）		 (1) 电器铭牌上的标注值
(2) 交流电表读数
(3) 计算电功、电功率、电热、保险丝熔断电流。
平均值 图像与时间轴围成的面积与时间的比值 $\bar{E} = n\frac{\Delta \Phi}{\Delta t}$
$\bar{I} = \frac{\bar{E}}{R+r}$		 计算通过电路横截面的电荷量 $q = \bar{I} \Delta t = n\frac{\Delta \Phi}{R}$ 。

解题小贴士：拿到交变电流题目，第一反应是问自己：这道题让我求什么？是热量（用有效值），还是电荷量（用平均值），或者是判断电容器能否被击穿（用最大值）？把这个想清楚，题目就成功了一半。

三、涡流、电磁阻尼与电磁驱动

这部分内容是电磁感应定律在块状金属中的具体应用，多以概念题、选择题形式出现 。

1. 涡流

  • 定义：当块状金属处在变化的磁场中或相对于磁场运动时，金属内部会产生感应电流。这种电流在金属内部形成闭合回路，很像水的漩涡，所以叫涡流 。
  • 应用与防止：
    • 应用：电磁炉（利用涡流的热效应加热食物）、真空冶炼炉（利用涡流高温熔化金属）、金属探测器（探测金属）。
    • 防止：在变压器、电动机的铁芯中，为了减少涡流造成的热量损失（也叫铁损），通常采用相互绝缘的硅钢片叠压而成，而不是用整块铁芯。这样做可以增大电阻，从而减小涡流 。

2. 电磁阻尼

  • 定义：当导体在磁场中运动时，导体中产生的感应电流（涡流）会使导体受到一个阻碍其运动的安培力，这种现象叫电磁阻尼 。
  • 典型实例：
    • 磁电式仪表的铝框：当线圈转动时，铝框切割磁感线产生涡流，涡流受到的反向安培力会使指针快速停下来，便于读数 。
    • 灵敏电流计运输保护：运输时将两个接线柱用导线连接起来，当线圈晃动时，产生的感应电流会形成一个“电磁阻尼”力，保护指针不被撞坏 。

3. 电磁驱动

  • 定义：如果磁场相对于导体运动（旋转），或者磁场本身在变化，那么导体中产生的感应电流会使导体受到安培力，从而跟随磁场运动，这种现象叫电磁驱动 。
  • 典型实例：
    • 感应式异步电动机：其基本原理就是通过旋转的磁场驱动转子转动。
    • 演示实验：一个可以自由转动的铝框，当你在它附近旋转一个磁铁时，铝框会跟着磁铁转动起来，但转速总是小于磁铁的转速 。

四、自感与互感

这部分研究的是线圈自身的电磁感应现象（自感）和相邻线圈间的电磁感应现象（互感）。

1. 自感

  • 定义：由于线圈本身的电流发生变化而产生的电磁感应现象 。
  • 自感电动势：
    • 公式：$$E = L\frac{\Delta I}{\Delta t}$$
    • 方向：总是阻碍原电流的变化。
      • 当原电流增大时，自感电动势方向与原电流方向相反，阻碍其增大。
      • 当原电流减小时，自感电动势方向与原电流方向相同，阻碍其减小 。
    • 作用：它只是“延缓”了电流的变化，但不能“阻止”或“改变”电流变化的最终结果 。
  • **自感系数 $L$**：
  • 决定因素：由线圈本身的特性决定，如线圈的匝数、横截面积、长度、有无铁芯等。匝数越多、截面积越大、有铁芯，$L$ 就越大 。
  • 单位：亨利，符号 $H$，$1,\mathrm{H}=10^3,\mathrm{mH}=10^6,\mu\mathrm{H}$ 。
  • 两类自感现象对比（非常重要！） ：
现象 电路特点 现象分析
通电自感 线圈与灯泡串联后并联 开关闭合瞬间，灯泡逐渐变亮（而不是立即亮），因为线圈产生的自感电动势阻碍电流的增加。
断电自感 线圈与灯泡并联 开关断开瞬间，灯泡不会立即熄灭，而是逐渐熄灭，甚至可能闪亮一下再熄灭。
闪亮条件：流过线圈的电流 $I_L$ 大于流过灯泡的原电流 $I_{灯}$。

2. 互感

  • 定义：两个相互靠近的线圈，当一个线圈中的电流变化时，在另一个线圈中产生感应电动势的现象 。
  • 应用与防止：
    • 应用：变压器、收音机里的磁性天线，都是利用互感现象来传递能量或信号 。
    • 防止：在电路板设计中，要设法减小电路间的互感，防止相互干扰 。

五、解题思路点拨

  1. 法拉第电磁感应定律：计算电动势首选 $E = n\dfrac{\Delta\Phi}{\Delta t}$（平均值）或 $E = BLv$（瞬时值或平均值）。如果需要求电荷量 $q$，必然要用到 $\bar{E} = n\dfrac{\Delta\Phi}{\Delta t}$。
  2. 交变电流：拿到题目先确定研究对象是“四值”中的哪一个。
  3. 自感现象：分析通电自感时，记住线圈“抗拒电流增加”；分析断电自感时，记住线圈“努力维持电流不变”，此时线圈相当于一个“电源”。
  4. 涡流：凡是看到块状金属、变压器铁芯发热、仪表指针快速停下、电磁炉等关键词，立刻想到涡流。
